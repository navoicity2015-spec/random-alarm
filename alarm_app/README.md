# Будильник со случайным временем

## Установка Flutter (один раз)

### Шаг 1 — Скачай Flutter
Перейди на https://docs.flutter.dev/get-started/install/windows/mobile
Скачай архив, распакуй в папку C:\flutter

### Шаг 2 — Добавь в PATH
Открой «Переменные среды» → PATH → добавь C:\flutter\bin

### Шаг 3 — Скачай Android Studio
https://developer.android.com/studio
Установи, запусти → SDK Manager → установи Android SDK

### Шаг 4 — Проверь всё
Открой терминал (cmd) и запусти:
```
flutter doctor
```
Все пункты должны быть зелёными (кроме iOS — это нормально).

## Запуск приложения

### Шаг 1 — Открой папку проекта
Скопируй папку `alarm_app` куда-нибудь удобно (например, C:\projects\alarm_app)

### Шаг 2 — Установи зависимости
```
cd C:\projects\alarm_app
flutter pub get
```

### Шаг 3 — Подключи телефон
- Включи «Режим разработчика» на телефоне:
  Настройки → О телефоне → нажми 7 раз на «Номер сборки»
- Включи «Отладка по USB»
- Подключи телефон кабелем к компьютеру
- Разреши отладку на телефоне когда появится запрос

### Шаг 4 — Запусти
```
flutter run
```

### Шаг 5 — Собери APK (чтобы установить без компьютера)
```
flutter build apk --release
```
APK будет в: build\app\outputs\flutter-apk\app-release.apk
Перенеси на телефон и установи.

## Что умеет приложение

- Задаёшь диапазон (например 7:00 – 8:00)
- Приложение случайно выбирает время внутри диапазона
- Ты не знаешь точное время до момента звонка
- Чтобы отключить — нужно решить задачку (сложение, умножение, etc.)
- Будильник срабатывает даже если экран заблокирован
